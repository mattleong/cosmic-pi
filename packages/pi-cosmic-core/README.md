# pi-cosmic-core

Shared Effect v4 foundations for the extensions in the cosmic-pi workspace.

This package does not register a pi extension. Its initial API exposes Pi's host API as an Effect service and creates a managed runtime for Pi-hosted programs.

Shared schemas, lifecycle services, platform layers, and test support will move here as each extension is migrated. The package is under active development on the Effect-first rearchitecture branch, and its API is not stable yet.
